# Omnisoft Gym

Εφαρμογή διαχείρισης γυμναστηρίου (multi-tenant): προγράμματα προπόνησης, καταγραφή, πρόοδος, κανόνες progression και παρουσίες.

- **Frontend:** στατικές σελίδες (HTML/CSS/JS) σε GitHub Pages
- **Backend:** Supabase (Postgres + Auth + RLS)

## Ρόλοι
| Ρόλος | Τι κάνει |
|---|---|
| Διαχειριστής πλατφόρμας | εγκρίνει νέα γυμναστήρια |
| Ιδιοκτήτης | ρυθμίσεις γυμναστηρίου, προπονητές, ό,τι κάνει ο προπονητής |
| Προπονητής | αθλητές, ασκήσεις, προγράμματα, παρουσίες |
| Αθλητής | βλέπει το πρόγραμμά του, καταγράφει, βλέπει την πρόοδό του |

## Βάση δεδομένων
Τα scripts στον φάκελο `sql/` τρέχουν με τη σειρά στον SQL Editor του Supabase.
Το `05_seed_demo.sql` περιέχει μόνο φανταστικά demo δεδομένα.

## Ρύθμιση
Στο `config.js` μπαίνει το **publishable** key του Supabase (ποτέ το secret / service_role).
